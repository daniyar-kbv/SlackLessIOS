# SlackLess

SlackLess is a productivity app to monitor and limit time spent on distracting apps. Built using Apple’s Screen Time APIs with SwiftUI and Clean Architecture.

## Features
- DeviceActivityMonitor & Shield Extensions
- Daily usage dashboards
- App time limits
- Push notifications

## Tech Stack
SwiftUI, Firebase, RxSwift, Clean Architecture, DeviceActivity APIs
